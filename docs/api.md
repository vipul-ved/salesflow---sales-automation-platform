# API & Developer Documentation

## REST Endpoints
- `GET /api/leads` - List leads with filters
- `POST /api/leads` - Create new lead
- `PATCH /api/leads` - Update lead status
- `GET /api/deals` - Fetch sales pipeline & deals
- `POST /api/deals` - Create new deal
- `PATCH /api/deals` - Move deal stage (Drag & Drop)
- `POST /api/ai/chat` - AI assistant server-side tool execution
- `POST /api/ai/email-gen` - AI sales email generator
- `POST /api/developer/api-keys` - Generate SHA-256 API key
